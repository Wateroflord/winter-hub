# Winter Hub

Один лаунчер для приложений Winter: **КБЖУ Трекер** (с плагинами), **Dota Draft** и **Winter Chat**. Телефон (Android) и ПК (Windows).

- Скачай хаб: раздел Releases → `Winter-Hub-arm64-v8a.apk` (почти все телефоны) или `Winter-Hub-Setup.exe` (ПК).
  Очень старый телефон — `Winter-Hub-armeabi-v7a.apk`.
- В хабе: установка, обновление в один клик, запуск, удаление, новости.
- Хаб сам выбирает версию APK под процессор телефона (её можно сменить в карточке приложения).
- Шахматы, Сапёр, Winter Paint, Уроки рисования, Winter Music, Выживание в лесу, Winter Walks, Winter Language,
  Просрочка и Mog Battle — теперь плагины внутри КБЖУ Трекера (шторка сверху).
- Список приложений и новости — в `catalog.json` (хаб читает его из этого репозитория).
- Общая сборка всех приложений и общий код (`packages/winter_core`) — тоже здесь, см. `ci/README.md`.
