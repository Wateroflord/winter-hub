# Winter Sprites

Помощник для пиксель-арта на ПК (работает и на телефоне): открываешь спрайт-лист из Aseprite, Piskel или Winter Paint —
и дальше:

- **Нарезка** — по размеру кадра (с отступом и промежутками) или по сетке «колонки × строки», кнопка «Угадать».
  Пустые кадры видно сразу. Нажми на кадры — выберешь, какие пойдут в анимацию; «Ряд N» — весь ряд.
- **Анимация** — предпросмотр с нужной скоростью, пинг-понг, увеличение, фон шахматка / тёмный / светлый / хромакей.
- **Палитра** — все цвета листа по частоте; нажми на цвет и замени его на всём листе (перекрасить скин, убрать фон).
  Сохранить палитру в `.gpl` (Aseprite, GIMP) или скопировать HEX.
- **Экспорт** — кадры отдельными PNG, GIF, новый ровный лист + `.json` с координатами кадров, увеличение ×2/×4/×8 без размытия.
- **Собрать лист** — из отдельных картинок (`walk_1.png`, `walk_2.png`…) в один лист по порядку номеров.

Подсказки для движков есть прямо на вкладке «Экспорт» (Unity: Point filter, Grid By Cell Size; Roblox: ImageRectOffset).

Ставится через **Winter Hub**. Сборка — общий workflow из `winter-hub` (`.github/workflows/build.yml`).
