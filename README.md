# Winter Hub

Один лаунчер для приложений: **Dota Draft** и **КБЖУ Трекер**. Телефон (Android) и ПК (Windows).

- Скачай хаб: раздел Releases → `Winter-Hub.apk` (телефон) или `Winter-Hub-Setup.exe` (ПК).
- В хабе: установка, обновление в один клик, запуск, удаление, новости.
- Список приложений и новости — в `catalog.json` (хаб читает его из этого репозитория).
